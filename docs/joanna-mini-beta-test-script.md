# Joanna Mini Beta Test Script

Goal: one content-manager pass before Tuesday, June 23.

## Script

1. Open hosted beta URL.
2. Log in as Reviewer/Joanna.
3. Browse asset grid.
4. Search for `Bible`, `prayer`, `fellowship`, `worship`, and `flowers`.
5. Filter by event/source, rights/usage, review status, and contributor where available.
6. Open two asset details and inspect date, event/source, usage, rights, people/minors, and notes.
7. Open review queue.
8. Pick one safe-looking item and decide whether evidence is enough for internal or public approval.
9. Pick one uncertain item and reject, archive, or flag rights issue.
10. Edit title/tags/notes where available.
11. Switch to Contributor only if Hali gave a separate contributor credential.
12. Upload one or two photos, or submit a source-link-only intake.
13. Confirm new intake defaults to `Needs Review / Do Not Publish`.
14. Send feedback.

## Feedback Questions

- Which fields were confusing?
- Which fields felt unnecessary for first upload?
- What categories are missing?
- Where did rights/copyright feel unclear?
- Did search find the photos you expected?
- Did review decisions feel safe or too easy?
- What would block you from using this weekly?

## Timing

No Saturday/Sunday availability required. One weekday pass is enough.
